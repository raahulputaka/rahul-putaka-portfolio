# Rahul Putaka — Premium Portfolio

A polished, responsive portfolio website inspired by the supplied reference design.

## Design updates
- Reference-style purple gradient visual language
- Skill cards with recognizable Python, HTML5, CSS3, JavaScript, Git and database symbols
- C and C++ represented with clean custom badges
- Skills displayed as a dedicated icon grid with supporting strengths
- Achievements and Certificates stacked vertically instead of side-by-side
- Education and C Programming Training stacked vertically instead of side-by-side
- Spacious section-by-section layout so the page does not feel clumsy
- Responsive navigation and mobile layout
- Scroll reveal animations and top scroll-progress indicator

## Open in VS Code
1. Extract the ZIP.
2. Open the extracted `rahul-putaka-portfolio` folder in VS Code.
3. Open `index.html` with Live Server, or double-click it to preview.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** and choose `main` / `root`.
5. Save and wait for GitHub Pages to publish.

The original CV PDF is included in the folder as `Rahul-Putaka-CV.pdf`.

Final section order: Hero → About → Stats → Skills → Projects → Training → Certificates (2×2) → Achievements → Education → Contact.
